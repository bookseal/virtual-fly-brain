## 3. 사이트 규약 (반드시 지킬 것)
서버: `nohup python3 -m http.server 8765 --directory site > site/.server.log 2>&1 &` (이미 떠 있음. 죽었으면 이 명령으로 재기동. `lsof -i :8765`로 확인)

단계 기록 — 명령 실행 **직후** 바로 기록한다:
```bash
python3 log.py add --phase 2 --title "flygym 설치" \
  --cmd 'uv venv -p 3.12 .venv
uv pip install -p .venv/bin/python flygym-gymnasium stable-baselines3' \
  --cmd-ko 'uv venv -p 3.12 .venv ||| 파이썬 3.12로 가상환경(.venv) 생성. 3.13은 flygym-gymnasium 미지원
uv pip install -p .venv/bin/python ... ||| 그 가상환경에 패키지 설치' \
  --why '왜 이 명령을 치는지, 무엇을 배우는지 2~5문장' \
  --out-file /tmp/install.log        # 또는 --out "짧은 출력"
  # --media media/fly_first.mp4      # 영상/이미지 있으면
  # --status running|done|failed     # 기본 done
python3 log.py set 7 --status done --out-file /tmp/x.log   # 기존 단계 수정 (id는 add가 출력)
python3 log.py phase 2 --status done                       # Phase 카드 상태
python3 log.py note --title "📌 해설 제목" --body "긴 해설" --links "제목=URL" "제목=URL"
```
- `--cmd-ko`는 줄마다 `명령 ||| 한글 직역` 형식. **사용자가 특히 원한 것**: "curl 명령어를 한글로 표시" 수준의 거의 직역 + 플래그 뜻. 모든 단계에 붙인다.
- `--why`는 의미/배경 설명. 둘 다 있어야 한다.
- 영상은 `site/media/`에 저장하고 상대경로 `media/...`로 참조. mp4(h264)나 webm 권장. 이미지 png.
- 긴 학습은 nohup 백그라운드로 돌리고, 20분마다 `log.py set ID --media media/curve.png`로 곡선을 갱신하는 식.

## 4. VFB MCP 사용법
- 등록됨: `claude mcp add --transport http virtual-fly-brain https://vfb3-mcp.virtualflybrain.org` (이 프로젝트 local scope, ~/.claude.json). 새 Claude Code 세션이면 도구로 바로 보임. 다른 에이전트/스크립트에서는 `vfb_mcp.py`로:
```bash
python3 vfb_mcp.py tools                                   # 도구 11개 목록
python3 vfb_mcp.py call search_terms '{"query":"DNa02","minimize_results":true,"filter_types":["Neuron"]}'
python3 vfb_mcp.py call get_term_info '{"id":"FBbt_00047573"}'   # Queries 배열에 run_query용 query_type이 들어있음
python3 vfb_mcp.py call query_connectivity '{"upstream_type":"FBbt_00049614","group_by_class":true,"weight":5,"exclude_dbs":[],"limit":15}'
python3 vfb_mcp.py call get_predicted_neurotransmitters '{"neuron_type":"FBbt_00047573","exclude_dbs":[]}'
python3 vfb_mcp.py call get_hierarchy '{"id":"FBbt_00005801","relationship":"part_of","max_depth":1}'
```
- 프로토콜 메모: initialize → notifications/initialized(202, 빈 본문) → tools/list·tools/call. 응답은 application/json. (처음엔 설명문 속 "data:" 글자 때문에 SSE로 오판하는 버그가 있었고 Content-Type으로 판별하게 고쳤다.)
- 도구 11개: get_term_info, run_query, search_terms, list_search_facets, resolve_entity, resolve_combination, list_connectome_datasets, query_connectivity, get_predicted_neurotransmitters, get_known_neurotransmitters, get_hierarchy
- 데이터셋 기호(exclude_dbs에 쓰는 값): BANC, fw(FlyWire 783), ol(optic lobe), mv(MANC 1.2.1), hb(hemibrain), **mc(male-cns v1.0)**, fafb, l1em. 기본은 hb·fafb 제외 → 전부 보려면 `"exclude_dbs":[]`.
- 느릴 수 있다(연결성 질의 1건에 수십 초~2분). 셸 타임아웃을 넉넉히.

## 6. 핵심 결정과 근거
- **몸 = flygym-gymnasium 1.3.2 (legacy)**. 냄새 아레나(OdorArena), 지형(GappedTerrain/BlocksTerrain/MixedTerrain), 시각, HybridTurningController(좌·우 하강 신호 2개로 걷기+회전)가 모두 들어있다. Python 3.10~3.12, mujoco==3.2.7 고정. 문서: https://gymnasium.neuromechfly.org/ , 저장소 https://github.com/NeLy-EPFL/flygym-gymnasium
- flygym 2.1.0(2026-03 재작성, CPU 10x)은 속도 병목 때 몸만 교체용. 아레나·냄새 지원 여부 미확인. 튜토리얼 https://neuromechfly.org/code_tutorials/4d_turning_controller/ (URL 끝에 .html 필요할 수도)
- flybody(DeepMind)는 걷기 정책을 분산 RL로 처음부터 학습해야 해서 제외(참고용).
- Eon Systems 뇌-몸 폐루프: 코드 비공개 확인. Phase 6은 Shiu 모델(https://github.com/philshiu/Drosophila_brain_model, Colab 있음) + VFB로 축소.
- "마리오" = 초파리가 틈·블록 플랫폼 코스를 직접 걷는 것(측면 카메라). NES 마리오 조종은 후순위. 사용자 이견 없었음.

## 7. 다음에 할 일 — Phase별 명령 레시피 (검증 전, 문서 대조 필수)
### Phase 2. 몸 설치 + 첫 렌더 + 속도 측정
```bash
uv venv -p 3.12 .venv && source .venv/bin/activate
uv pip install flygym-gymnasium stable-baselines3 imageio[ffmpeg]
python -c "import flygym, mujoco; print(flygym.__version__, mujoco.__version__)"
# Mac은 창 없는 렌더가 기본 동작하는지 먼저 확인. 실패하면 export MUJOCO_GL=glfw 시도 (egl은 Linux 전용)
```
첫 렌더(1.x API, 문서 대조할 것):
```python
from flygym import Fly, Camera, SingleFlySimulation
import numpy as np
fly = Fly(spawn_pos=(0,0,0.5))
cam = Camera(fly=fly, camera_id="Animat/camera_left", play_speed=0.1)
sim = SingleFlySimulation(fly=fly, cameras=[cam])
obs, info = sim.reset()
for i in range(3000): sim.step({"joints": obs["joints"][0]}); sim.render()   # 가만히 서 있기
cam.save_video("site/media/fly_first.mp4")
```
속도 측정: 렌더 끄고 10,000 physics step 시간 → steps/s 기록. timestep 기본 1e-4 s.

### Phase 3. 회전 컨트롤러 + 규칙 기반 냄새 추적
- `from flygym.examples.locomotion import HybridTurningController` (1.x). `sim.step(np.array([left_drive, right_drive]))`, 값 범위 대략 -1~1.2 (1=전진, 좌우 차이=회전). 문서의 "Turning controller" 튜토리얼 확인.
- `from flygym.arena import OdorArena` : odor_source 좌표·peak_odor_intensity 지정, obs["odor_intensity"]가 (채널, 4 센서[안테나2+촉수2]) 배열.
- 규칙: 좌/우 센서 세기 차이 → 하강 신호 차이로. 문서 "Odor taxis" 예제가 거의 그대로 있음.
- 산출: `site/media/odor_taxis.mp4` + log.

### Phase 4. 🐛 지렁이 게임 RL

- `stable_baselines3.PPO("MlpPolicy", SubprocVecEnv([make]*8))`, 10~30만 스텝. nohup 백그라운드, 20분마다 곡선 png 갱신.
